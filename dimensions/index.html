Dimensions

Press D, then click an edge. A single selected or active edge may be picked automatically.

Labels show the edge length, nearby parallel distances and angles.

Change a value

  • Click a label: type a replacement.
  • Drag a label horizontally: adjust the value.
  • Ctrl while dragging: use increments.
  • Shift while dragging: move ten times more finely.
  • Enter / click: confirm typed input. Releasing a drag confirms it.
  • Esc / right-click: cancel the edit.

Ctrl + A replaces the whole value; Ctrl + V pastes. Lengths accept units such as mm, cm, m, ft and in. Angles use degrees.

Fixed end and locks

Outside input, press Tab or click the support icon to switch the fixed endpoint.

Hover a value to reveal its padlock. Click it to lock or unlock that dimension. Locked values are kept while neighboring geometry adjusts. If constraints conflict, cancel or unlock a value.

Locks last only while Dimensions is active. Leaving this mode clears them.

Return to drawing

D / Esc, outside input, returns to drawing. Right-click deselects the edge. Ctrl + Z or Backspace, outside input, undoes a validated change.
